# [UI/UX 혁신] Glassmorphism 2.0 기반 지도 탐색 대시보드 리디자인 기획안

기존의 산만하고 투박했던 프론트엔드 대시보드를 2026년 최신 **"Spatial Glassmorphism 2.0 & Cockpit UI"** 디자인 표준으로 전면 재설계합니다.
화면을 무겁게 가리는 정보 과부하 요소를 배제하고, 세련된 글래스 패널, 체계적인 컬러 파렛트, 프로그레시브 디스클로저(Step-by-step 팝업/아코디언)를 도입합니다.

## 1. 현재 대시보드 디자인 문제점 진단 (Pixel & UX Audit)

| 문제 영역 | 현재 상태 진단 | 개선 방향 (Glassmorphism 2.0) |
| :--- | :--- | :--- |
| **정보 레이아웃 (Layout)** | 사이드바 하나에 8개 이상의 조잡한 섹션이 수직 나열되어 스크롤 폭탄 발생 | **플로팅 글래스 패널 + 3대 메인 탭 분리** 및 필요시 팝업/아코디언 노출 (Progressive Disclosure) |
| **컬러 시스템 (Color)** | 주황/보라/연보라/노랑/초록 원색들이 난립하여 눈이 피로함 | **Sleek Indigo & Slate-900 듀오톤** 기반의 세련된 프리미엄 컬러 팔레트 통일 |
| **모임/벙 맛집 필터 UI** | 4가지 조건(인원/예산/시간/분위기)이 사이드바의 절반을 차지하여 지도를 방해 | **"스마트 모임 필터" 모달/컴팩트 팝업**으로 전환하여 사이드바 공간 극대화 |
| **장소 & 혜택 카드 UI** | 단순 borderbox 기반의 저가형 MVP 디자인 | **Hover elevation, 미세 폰트 계층, 뱃지 레이아웃**으로 현대적 카드 완성 |

## 2. 디자인 시스템 및 컬러 파렛트 정의

* **Background Surface**: `rgba(255, 255, 255, 0.88)` + `backdrop-filter: blur(16px)` + `border: 1px solid rgba(226, 232, 240, 0.8)`
* **Primary Brand Accent**: `#4F46E5` (Indigo-600) ~ `#6366F1` (Indigo-500)
* **Secondary Accent**: `#8B5CF6` (Violet-500) & `#10B981` (Emerald-500)
* **Text & Contrast**: `Slate-900` (`#0F172A`, Heading) / `Slate-600` (`#475569`, Body)
* **Shadows & Depth**: `box-shadow: 0 20px 25px -5px rgba(0,0,0,0.08), 0 8px 10px -6px rgba(0,0,0,0.04)`

## 3. 주요 변경 컴포넌트 설계

### 3.1 3대 핵심 메인 탭 네비게이션
1. **`📍 내 주변 탐색`**: 통합 키워드 검색, 반경 선택(1/3/5km), 카테고리 퀵 칩 (맛집, 카페, 병원 등).
2. **`🍱 맞춤 모임 & 메뉴`**: 벙 맛집 모임 조건 팝업 모달 + 점심/저녁 뭐먹지 스마트 추천.
3. **`🎁 정부 혜택`**: 1인 창조기업, 소상공인 등 상황별 복지 혜택 검색 및 맞춤 지원 목록 카드.

### 3.2 벙 맛집 & 뭐먹지 조건 팝업 모달 (Smart Condition Modal)
- 사이드바 내 수직 폭탄 폼 제거.
- `⚡ 모임 조건 설정` 버튼 클릭 시 지도 중앙 위에 매끄럽게 뜨는 **Glassmorphism Modal Layer** 제공.

### 3.3 통합 서치 헤더 & 카테고리 칩 롤링 UI
- 위치 선택 드롭다운과 검색창을 일체형 돋보기 헤더로 통합.
- 9개 칩 아이콘을 가로 가변형 아이콘 칩 바(Horizontal Chip Bar)로 정돈.

## 5. Verification Plan

### Manual Verification
1. **Visual & Layout Check**:
   - 새로 리디자인된 패널이 지도를 가리지 않고 세련된 글래스모피즘(blur, subtle shadow, sleek border)을 제대로 유지하는지 확인.
   - 3개 메인 탭(내 주변 탐색, 맞춤 모임&메뉴, 정부 혜택) 간 전환이 매끄럽고 여백과 visual hierarchy가 깔끔한지 검증.
2. **Interactive Feature Verification**:
   - "스마트 모임 필터" 모달이 정상 팝업되고 인원/예산/시간/분위기 선택 후 검색이 동작하는지 테스트.
   - 데이트 코스 2~3단계 추천, 공공 카페 반경 검색, 정부 혜택 목록 검색이 런타임 오류 없이 작동하는지 확인.
3. **Responsive & Mobile/Desktop View**:
   - 패널 접기/펼치기 및 반응형 레이아웃 정상 동작 확인.
